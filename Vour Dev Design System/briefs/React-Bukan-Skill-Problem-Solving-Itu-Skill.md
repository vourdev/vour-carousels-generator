# Slide 7 — Solution

## Page Counter
06 / 08

## Eyebrow
BAGAIMANA MELATIHNYA

## Headline
Latih Problem Solving  
**Tiap Hari.**

## Step 1
Coba pecahin satu masalah TANPA framework dulu.  
Buka editor, tulis solusi pakai vanilla JS. Baru pindahin ke React kalau perlu.

## Step 2
Baca codebase orang lain seminggu sekali.  
Pilih open-source repo, baca satu fitur, tebak kenapa mereka pilih pendekatan itu. Lalu cari tahu.

## Step 3
Ajarin konsepnya, bukan sintaksnya.  
Kalau bisa jelasin "kenapa pakai useEffect" tanpa nyebut React, kamu paham konsepnya. Kalau cuma bisa jelasin sintaks, kamu hafal API.

# Caption

"Saya udah 3 tahun pakai React. Kenapa salary stuck?"

Karena React bukan skill. React tools.

Yang dibayar mahal bukan yang hafal hook paling banyak — tapi yang bisa lihat masalah baru, urai jadi sub-masalah, dan pilih tool yang tepat (kadang bukan React sama sekali).

Senior dev yang saya kenal bisa pindah dari React ke Vue ke Solid dalam seminggu. Karena yang mereka kuasai bukan API-nya. Tapi cara berpikirnya.

Save carousel ini buat baca ulang tiap kali kamu mau "belajar framework baru" 🙏

Komen di bawah — framework apa yang lagi kamu pelajari sekarang, dan masalah apa yang lagi mau kamu pecahkan dengan itu?
