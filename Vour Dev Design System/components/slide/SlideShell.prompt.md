**SlideShell** — the only canvas wrapper for a Vour Dev slide. Fixed at 1080×1350 with editorial cream + halo background and IG padding (`96 / 80 / 80`). Editorial is the only surface.

```jsx
<SlideShell>
  <PageCounter index={2} total={10} />
  <Eyebrow>What is it</Eyebrow>
  <h1>What is a DESIGN.md file?</h1>
</SlideShell>
```
