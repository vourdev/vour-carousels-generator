**DarkCallout** — the dark `--ed-callout-ink` banner that lands a take. Max one per slide.

```jsx
<DarkCallout icon="lucide:check-circle">
  Claude reads that description and actually respects the constraint.
</DarkCallout>
```

Icon container is 40×40 with opaque white-8% fill; icon glyph is 24×24 `--ed-orange`.
