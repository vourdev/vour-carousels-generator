[Component · ImagePlate]

Any screenshot goes into an ImagePlate.

Cream paper + a raw image reads as pasted-in. Wrap every screenshot in an ImagePlate so it inherits the editorial ink outline and warm shadow — same visual weight as the diagram cards, so the slide reads as one composition.

1 · Pick the variant by subject

window-mac — terminal / IDE / native app.

window-web — browser-based web app. Pass url="" for the address pill.

phone — iOS / Android screen.

framed (default) — anything else with a real bounding rectangle.

plain — logo / isolate with no natural frame; adds rounded corners + soft shadow only.

2 · Size the plate

Inside a .diag-wrap on a mockup slide? Omit ratio — the plate fills the wrap and obeys the §14 proportion contract.

Inline on a text slide? Give it ratio="16 / 10" (or 4 / 3, 9 / 19 for phone) so it has a definite size.

3 · Fit

fit="cover" (default) — the image fills the plate and center-crops. Good for hero screenshots.

fit="contain" — the whole image is visible against cream paper. Use for logos, charts, or screenshots where the edges matter.

4 · Caption

Add a captionEyebrow (orange, ALL CAPS) + caption (mono, brown-ink) on any mockup slide. One line max. Say what the image IS, not what it means — the headline already said that.

Skip the caption on comparison pairs where the headline covers both.
