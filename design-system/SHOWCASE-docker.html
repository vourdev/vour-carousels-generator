03 / 08
DOCKERFILE

Baris Ini Yang Jebol.

Copy semua file dulu, install belakangan. Cache-nya rusak.
Dockerfile
FROM node:20-alpine
WORKDIR /app
COPY . .            # ← semua kode masuk
RUN npm install     # ← cache mati di sini
CMD ["npm", "start"]
Ganti kode apa pun → dua baris ini ngulang.
04 / 08
CARA KERJANYA

Tiap Baris Jadi Satu Layer.

Docker cache per layer. Satu layer berubah, semua di bawahnya ikut ulang.
FROM node:20-alpinecached
WORKDIR /appcached
COPY . .berubah →
RUN npm installikut ulang
CMD npm startikut ulang
Catatan
Layer paling sering berubah, taruh paling bawah.
05 / 08
URUTAN BENAR

Copy package.json Dulu.

Install duluan pakai file yang jarang berubah. Kode masuk belakangan.
Dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./  # jarang berubah
RUN npm install        # ← ke-cache
COPY . .               # kode berubah, aman
CMD ["npm", "start"]
Sekarang npm install cuma jalan kalau dependency berubah.
